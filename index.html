Kismet Design System

The Figma system, in HTML.

Same tokens, same components, same rules as the Figma file Kismet Design Explorations. Use it to build real, responsive prototypes: mobile first, five color themes, and text metrics trimmed to cap height so spacing matches the designs.

Start a prototype
<!doctype html>
<html lang="en" data-theme="electric">   <!-- electric · submarine · salad · skittles · lego -->
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="css/kismet.css">
  <script src="js/kismet.js" defer></script>
</head>
<body><div class="k-page"> …components… </div></body>
</html>

Rules

  • Mobile first. Base CSS is the Mobile mode of the Figma variables; the Desktop mode applies from 1024px.
  • Tokens only. Colors, spacing, radius and type come from var(--…). Use semantic tokens (--color-bg-*, --color-text-*, --color-action-*), never primitives.
  • Themes. data-theme on <html> switches the palette. Never pair two free accents: use the paired tokens (nav, top bar, marquee, hero panel) so foreground and background stay legible in all five themes.
  • Component height never changes between states (input focus, tabs, product card hover).
  • Photo headers always carry an overlay: gradient on desktop, flat color on mobile.
  • Product sliders on mobile always show their previous / next buttons right below the cards.
  • Swapping a product photo only changes the image — the white gradient of the card stays.
  • Primary CTA keeps white text on the brand color (accepted brand exception to the contrast rule).

Typography

One class per Figma text style: .text-{role}-{size}. Sans Plomb 98 Oblique for display, Apercu for everything else. Sizes switch to the Desktop mode at 1024px.

Spacing, sizes & radius

8pt scale. --layout-* and some --size-* tokens change between mobile and desktop.

Icons

<span class="k-icon k-icon--cart"></span>. They take the text color. Sizes: --sm 16, default 24, --lg 32.

Durations --duration-fast 150ms · --duration-base 250ms · --duration-slow 400ms. Easings --easing-standard, --easing-enter, --easing-exit, --easing-bounce.

Button

.k-btn + type (--secondary --neutral --inverse --ghost --link) + size (--sm --md --lg). Add --block for full width.
